### Hey, I'm Rafael 👋

I'm a software engineer from Brazil. I've been building things for over 15 years, from mobile apps and high-traffic platforms to backend systems, infrastructure and developer tools.

I've worked across fintech, payments, insurance and a few other industries. Somewhere along the way, I got particularly interested in what happens behind the scenes: how systems scale, how things communicate, how to make complex software simpler.

These days, I spend a lot of time with Go, distributed systems, AI, infrastructure and whatever interesting problem I happen to be working on.

I also have a habit of building tools because I couldn't find one that worked quite the way I wanted.

### Things I've built (and keep building)

Most of these started with a pretty simple thought: *"I wish this existed."*

**Developer tools & infrastructure**

- **[Lily DB](https://getcortexlabs.com/products/lily/)**: A native database workspace for macOS. Nine database engines, query tools, performance tracing, migrations and AI that actually understands what you're working with.
- **[Kiln](https://github.com/rafaelaugustos/kiln)**: Background jobs for Go, inspired by Hangfire. Uses your existing SQL database instead of requiring a separate message broker. Retries, scheduling, workflows, transactional enqueue and a dashboard included.
- **[Orbit](https://orbit.getcortexlabs.com/)**: Making server management and Kubernetes deployments less painful. Your infrastructure, without having to fight it.
- **[Barney Kube](https://getcortexlabs.com/products/barney/)**: A native Kubernetes client for macOS. Browse resources, inspect workloads, access terminals and forward ports without living in the command line.
- **[Marshall MQ](https://getcortexlabs.com/products/marshall/)**: A native Kafka and RabbitMQ client for macOS. Inspect queues, track down troublesome messages and understand what's really happening.
- **[Vue Router NS](https://github.com/rafaelaugustos/vue-router-ns)**: Bringing the Vue Router experience to NativeScript-Vue 3, with TypeScript, native navigation, guards, deep links and modals.
- **[Popup UI](https://github.com/RafaelAugustoS/react-native-popup-ui)**: Customizable popups for React Native.
- **[Vue Router NS](https://vue-router-ns.rafaelaugusto.dev/)**: Bringing the Vue Router experience to NativeScript-Vue 3, without giving up native navigation. Typed routes, guards, deep links, modals and tab navigation.
- **[Jolt](https://jolt.rafaelaugusto.dev/)**: Making animations in NativeScript feel effortless. Springs, keyframes, presets, stagger and sequences, all powered by native animations on iOS and Android. Works across NativeScript frameworks.

**AI & productivity**

- **[Cortex](https://getcortexlabs.com/products/cortex/)**: Persistent memory for Claude Code. Local-first, built to preserve useful context without wasting tokens.
- **[Ted Agent](https://getcortexlabs.com/products/ted/)**: A macOS AI agent that lives in the menu bar, right where I wanted one.
- **[Cortex Shelf](https://getcortexlabs.com/products/shelf/)**: A little productivity toolkit for the Mac notch. Clipboard history, notes, screenshots, files and a place to drop things.
- **[JobMorph](https://www.jobmorphai.com/)**: Helping people tailor their CVs to job applications using AI.

**A little outside the usual developer tooling**

- **[Yummo](https://getcortexlabs.com/products/yummo/)**: A restaurant operating system connecting menus, orders, kitchen, customers, staff and finances. Built for the web, desktop and mobile.
